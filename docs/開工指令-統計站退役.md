# 開工指令：canvas 的統計站退役

## 目標與動機

統計站已拆成獨立站 `stat.phenomcanvas.com`，canvas 這邊仍在服務同一批文章：
`canvas.phenomcanvas.com/statistics/judicial-ideal-points` 回 200，sitemap 裡有 94 個
統計網址（含 `/en/` 那一組與 `/statisticslab`）。canvas 的副本落後獨立站好幾次修訂，
2026-08-25 清掉的禁用詞在 canvas 上還有 13 處。同一批內容兩個網域各一份，搜尋結果互相
稀釋，而 canvas 那份沒有人在維護。

處置照 JIRS 與憲法法庭的既有做法：刪掉 canvas 的頁與資料，留 308 轉址，`/all` 的卡片
改指獨立站。

## 完全清除的安全性（動手前已查）

- canvas 沒有任何頁面 import `src/pages/statistics/` 底下的東西，`grep -rn "pages/statistics"
  src` 扣掉該目錄自己之後零命中。
- 統計那幾頁單向消費共用元件（`components/lab/ArticleLayout`、`Prose`、`Quiz`、
  `HoverCite`、`SourcesList`、`TermLink` 等），刪掉不影響別頁。
- `src/components/lab/ArticleMeta.jsx:32` 的預設 `tagBase = '/statistics/tags'`，而
  `ArticleMeta` 目前只有統計六篇在用。刪頁之後那個預設值指向不存在的路由，要一併處理。
- `src/pages/StatisticsLab.jsx:9` import `../data/statistics.json`，與資料檔一起刪。

## 要做的事

1. 刪 `src/pages/statistics/`（13 檔）、`src/pages/StatisticsLab.jsx`、
   `src/content/statistics/`（56 檔）、`src/data/statistics*.json`（9 檔）。
2. `src/App.jsx`：拿掉 `SPECIAL_ROUTES` 的 `GlossaryTerm`、`TagPage` 兩條（第 46、47 行），
   `PAGE_META` 的統計條目補上 `externalUrl`，並在 `App()` 回傳的 routes 陣列補一筆 entry。
   **`PAGE_META` 有 `externalUrl` 不會自己長出卡片**（第 604 行的註解與 JIRS 那次的教訓），
   卡片是從陣列長出來的，兩邊都要寫。
3. `public/_redirects` 補轉址，照第 3 到 14 行既有的寫法：`/statistics` 與 `/statistics/*`
   各一行，`/statisticslab` 一行，`/en/statistics/*` 一行。獨立站的網址形狀對得上，
   `stat.phenomcanvas.com/statistics/judicial-ideal-points`、`/statistics/glossary/ideal-point`、
   `/statistics/about` 實測都是 200，`:splat` 直接轉得過去。
4. `ArticleMeta` 的 `tagBase` 預設值改成必填，或整個刪掉該參數。
5. `sync-to-frontend.mjs` 在資料倉那邊的 canvas 目標要不要留，回報時列出來給站主決定。

## 驗收條件

1. `curl -s -o /dev/null -w "%{http_code} %{redirect_url}"` 對舊網址回 308，Location 指到
   獨立站對應路徑：`/statistics/judicial-ideal-points`、`/statistics/glossary/ideal-point`、
   `/statistics/about`、`/statisticslab` 各驗一次。
2. `/all` 點得到統計卡片並落到獨立站。點那顆卡片，不要自己組一個看起來等價的網址去開
   （2026-07-28 記過一次：用查詢字串進頁繞過了死掉的路由，驗收全過而按鈕是死的）。
3. `npm run build` 通過，產物的 sitemap 不再有 statistics 網址。
4. `npm run validate:extcards` 通過。
5. `grep -rn "statistics" src --include="*.jsx" --include="*.js"` 只剩 `App.jsx` 的
   externalUrl 條目與註解。

## 邊界

只動 `my-canvas-lab`。不准碰 `phenom-statistics`、`phenom-statistics-data`——貝蒂數那條線
有 13 個 commit 待推，站主判定該文尚未寫好，兩個倉這次都不動。

## 待裁定

- `/statisticslab` 在獨立站沒有對應路徑，轉到獨立站首頁還是 `/statistics/about`。
- `/statistics/tags/*` 與 `/en/statistics/*` 兩組要逐條核獨立站有沒有；`curl` 帶中文標籤
  查到 404，成因可能是編碼，也可能獨立站沒有標籤頁。

## 共用工作樹的 git 紀律

提交一律 `git commit -m "..." -- <明確路徑>`，絕不裸 `git commit` 或 `-am`；新檔先逐一
`git add <明確路徑>`。提交後 `git status` 確認別人的檔還在。禁止 `git commit --amend`。
push 只在站主說推送時做。
